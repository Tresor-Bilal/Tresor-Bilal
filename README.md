## 👨‍💻 About Me

I'm a **3rd-year Computer Science Bachelor's student at ECE Paris**, specializing in **Artificial Intelligence**.

I enjoy designing and building software and AI-powered applications, from backend development and database design to user interfaces, testing and production deployment.

During my internship at **Skills4Mind**, I contributed to the backend development of an **AI-powered document assistant**, working with Python, Flask, REST APIs, Large Language Models and Retrieval-Augmented Generation (RAG).

Alongside my studies, I work on personal and academic projects:

- **AEGIS:** A deployed platform for evaluating Large Language Models.
- **Altrejoah:** A multi-institution SaaS platform for academic and financial management.
- **FER2013:** Facial expression classification using classical Machine Learning.
- **FitZone:** Data Mining and customer analytics for business decision-making.

I also use AI coding assistants such as **Codex** to support my development workflow. I focus on understanding, reviewing, testing and simplifying the code rather than relying on generated solutions without verification.

🔭 **Currently exploring:** AI engineering, LLM evaluation, RAG, data processing and software architecture.

🌱 **Currently learning:** Deep Learning, neural networks and production-oriented AI development.

💼 **Looking for:** A **12-month apprenticeship starting January/February 2027** in Full-Stack Development, Software Engineering, Data or Artificial Intelligence.
